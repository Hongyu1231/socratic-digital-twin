## Limits and next review

This is retrieval-based context, not model training or comprehensive clinical
validation. The tutor receives text/background and bounded literature excerpts,
not image pixels; the student reviews the images. The six-phase scaffolds are
application-authored because the DOCX files do not include full marking scripts.
Faculty should review these scaffolds and source-record discrepancies before
assessment use. Small live samples cannot guarantee every future model response.

The machine's configured proxy was unavailable; real tests used a direct provider
connection without editing credentials. Run `npm run dev:materials -- --direct`
to use the same explicit connection choice. See `TEACHING_MATERIALS.md` for import,
test and restart instructions. Local learning sessions reset on server restart.

Nothing from these clinical archives has been published to the public demo. Any
future publication needs an appropriate access model and source-use review.
